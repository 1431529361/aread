# 开题报告与任务书：核验和填写说明

## 交付范围

- 已按用户提供的南京晓庄学院两份DOCX模板填写，不覆盖桌面原模板。
- 开题报告保留11行、4列的合并表格结构及三个正文部分、教师意见和备注栏；任务书保留6行、4列的合并表格结构。
- 题目：基于Agent与RAG的智能阅读系统的设计与实现。
- 正文区分现有Web原型和拟实现内容，不将尚未完成的改造或建议验收目标写成实际研究成果。
- 仅准备开题材料；未修改应用代码、运行数据库、书籍、密钥或Android内容，未提交Git。

## 提交前必须补充或确认

1. 姓名、学号、专业、指导教师、职称。当前为“待填写”，没有根据账号名猜测学生姓名或专业。
2. 两模板的学院名称本来不同：任务书为“信息工程学院、人工智能学院”，开题报告为“信息工程学院”。均暂按各自模板保留，请按实际学籍统一。
3. 2026-11-07开题日期沿用用户已确认信息；2027年1月至5月是拟定开发、论文和答辩准备进度，不代表学校官方日程。请由导师结合学院通知确认。
4. 教师意见、教师签字及签署日期留空，由相应人员填写；任务书正文为供导师审核的拟稿，不代表导师已经下达或批准。
5. 开题报告使用中文及英文正式期刊/会议论文，采用顺序编码引用；请在最终提交前结合学校完整写作规范核对引文标点、字体及引用格式。
