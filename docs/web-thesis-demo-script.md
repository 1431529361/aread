# 固定演示脚本（P4 答辩演练）

配套回归记录：`docs/baseline-results/p4-browser-regression.json`（连续 3 遍 × 12 流程全过）。
演示环境：`npm start` 后打开 http://localhost:3000；使用隔离演示账号与合成/默认书籍，不展示真实私人记忆与密钥。
模型不可用时：展示明确标注的已保存任务结果与历史会话，不冒充实时生成（见限制说明）。

## 流程与话术（12 步，单遍约 6–8 分钟，真实模型）

1. **登录**：注册/登录演示账号。话术：JWT 认证、bcrypt 密码、按用户隔离。
2. **上传**：书架上传 TXT（展示进度条）。话术：编码自动检测（UTF-8/GBK/BIG5），50MB 上限；v1 完整阅读/索引仅 TXT，如实限定。
3. **无索引问答**：打开未索引书提问书内事实。预期：明确"没有检索到足以回答的原文证据"，不凭印象作答。话术：证据门控——缺证不冒充有据。
4. **AI索引**：书架点击 AI索引。预期：弹窗显示分块数与模式（向量+BM25 / 仅BM25）。话术：章节边界+滑窗分块、sqlite-vec 向量、版本化建库互斥；Embedding 失败诚实降级。
5. **阅读+目录**：打开书，目录跳转章节。话术：locator 稳定定位（UTF-16 偏移+内容 hash）。
6. **问答+trace**：提问跨章节事实。预期：内联 trace 展示 searchInBook 调用与返回条数、证据卡。话术：统一入口自动取证，不需用户选模式。
7. **引用跳转**：点击回答中引用 chip / 证据卡"跳转原文"。预期：回到原文并高亮。话术：引用 ID 白名单校验、坐标核实、重开会话仍可跳转。
8. **会话恢复**：刷新页面→历史→点击会话。预期：消息与引用完整恢复。话术：服务端持久化、跨设备可续。
9. **记忆自动保存与纠正**：对话"我喜欢简洁的回答"→记忆弹窗见生效中 v1；再"更正：我喜欢详细的回答"→v2 确定性替代。话术：只从用户原话抽取、同键更新、版本乐观并发。
10. **记忆删除**：弹窗删除该记忆；历史回答的"本次参考的记忆"显示已删除。话术：删除屏障防旧任务回写；删除记忆≠删除聊天原话。
11. **故障演练**（可选，假模型或断网）：模型 500 → 状态 failed 有界结束；Embedding 500 → 首建降级 BM25、重建保留旧索引。话术：失败可见、不永久加载、不丢旧版本。
12. **任务复用**：读书笔记首跑展示 DAG 子 Agent 进度；二次点击直接展示已存结果（导出/重新生成可选）。话术：采样范围如实展示，结果持久化避免重复付费。

## 答辩追问准备

- "混合检索一定比 BM25 好吗？" → 保留集如实：本语料 BM25 Hit@5 略高于混合（见 P4 报告），混合收益依赖语料与 Embedding 质量；不承诺普遍提升。
- "记忆越来越多会更好吗？" → 分层对照与误注入率证据：治理（来源/作用域/门槛）比条数重要。
- "引用可点击等于正确吗？" → 区分引用合法率（自动 100%）与引用支撑率（人工标注）。
- "全书理解？" → 读书笔记为采样/局部分析，展示覆盖范围；完整覆盖列未来工作。
