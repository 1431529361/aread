## 简介
本指南面向 trae02airead 的"阅读模式"，帮助你在不同设备上获得舒适的阅读体验。经过前端UI重构后，应用现已从单页阅读界面转变为底部导航的多视图应用，包含bookshelf、history、settings等新视图。内容涵盖：
- 文章目录导航与章节切换
- 阅读进度跟踪
- 个性化阅读设置（字体大小、主题模式）
- 阅读舒适度优化
- 侧边栏功能、阅读历史记录、书签管理
- 多设备阅读体验优化建议与使用技巧

## 项目结构
前端采用原生 JavaScript + HTML + CSS 构建，后端基于 Express.js，数据库使用 sql.js（纯前端 SQLite 实现）。经过UI重构后，应用采用底部导航的多视图架构，核心文件如下：
- 前端入口与界面：public/index.html、public/app.js、public/styles.css
- 后端服务：server.js
- 数据库初始化与表结构：database.js
- 用户认证与 JWT：auth.js
- 项目依赖与脚本：package.json
- 项目说明与特性：README.md

## 架构总览
经过UI重构后，阅读模式采用多视图架构，通过底部导航实现视图切换，通过API与后端交互，实现：
- 用户认证与权限控制
- 书籍上传与内容解析
- AI 问答（流式 SSE）
- 历史记录与设置持久化
- 视图状态管理与路由

## 性能考虑
- **前端**
  - 视图懒加载：仅在切换时加载目标视图数据
  - 文本渲染：按章节拆分，避免一次性渲染超大 DOM
  - 滚动优化：使用 smooth scroll，减少重排
  - 事件节流：目录点击与滚动事件可增加节流
  - 底部导航状态缓存
- **后端**
  - 编码检测：优先尝试 UTF-8/BOM，再降级到其他编码
  - 文件上传：限制大小与类型，避免内存溢出
  - SSE：合理设置超时与断开重连策略
  - 数据库连接池优化

## 故障排除指南
- **无法打开书籍**
  - 确认文件格式为 TXT，且小于 50MB
  - 检查服务器日志与文件是否存在
  - 验证底部导航是否正确加载
- **编码乱码**
  - 系统自动检测编码，若仍乱码，尝试转换为 UTF-8
- **API 密钥问题**
  - 在设置页验证密钥有效性
  - 确保提供商与模型配置正确
- **问答无响应**
  - 检查网络与浏览器对 SSE 的支持
  - 查看控制台错误与后端日志
- **视图切换问题**
  - 检查底部导航组件是否正常加载
  - 验证视图数据请求是否成功
- **历史记录异常**
  - 清理浏览器缓存后重试
  - 检查数据库连接状态
