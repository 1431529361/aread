- **前后端分离架构**：`server.js` 作为核心入口，同时承载 Express API 路由与 `public/` 目录下的静态资源服务。
- **模块化后端设计**：通过 `auth.js` 处理 JWT 认证与密码哈希，`database.js` 封装 `sql.js` 实现内存级 SQLite 操作并同步至磁盘 `data.db`，主服务文件负责业务逻辑编排。
- **用户数据隔离机制**：所有业务数据（书籍元数据、API 密钥、自定义提供商）均通过 `user_id` 在数据库层面进行严格隔离，文件系统层则通过 `books/{userId}/` 目录结构实现物理隔离。
- **统一安全边界**：采用中间件模式保护受控接口，结合 AES-256-CBC 加密存储敏感 API 密钥，确保多租户环境下的数据安全。
