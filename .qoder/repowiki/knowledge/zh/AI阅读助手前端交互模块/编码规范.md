- 采用类 (Class) 结构组织代码，将 UI 元素初始化、事件绑定、业务逻辑（如认证、AI 交互、文件上传）封装在 `AIReadingAssistant` 类的方法中。
- 统一使用 `this.escapeHtml()` 工具方法对用户输入或动态生成的文本内容进行转义，防止 XSS 攻击。
- 通过 `data-view` 属性与 CSS 类名 `.active` 的配合，实现不同功能模块（阅读器、书架、设置等）的显隐控制与导航状态同步。
- 异步操作（如 API 请求、文件读取）普遍采用 `async/await` 语法，并在 `try...catch` 块中统一处理错误提示与 UI 状态恢复（如按钮 loading 状态移除）。
