- **单页应用架构 (SPA)**：采用原生 JavaScript (`app.js`) 实现，通过 `AIReadingAssistant` 类封装核心逻辑，利用 DOM 操作动态切换视图（阅读、书架、历史、设置）。
- **前后端分离通信**：通过 `apiFetch` 方法统一处理 HTTP 请求，自动注入 Bearer Token 进行身份验证，并处理 401 过期跳转。
- **流式响应处理**：在 `askAI` 方法中使用 `ReadableStream` 和 `TextDecoder` 解析 SSE (Server-Sent Events) 格式数据，实现 AI 回答的逐字渲染。
- **本地状态与持久化**：结合 `localStorage` 存储用户偏好（主题、字体、API 提供商选择）及临时会话状态，配合后端 API 同步历史记录与书籍元数据。
- **样式系统**：使用 `styles.css` 定义 CSS 变量体系，支持明亮、暗黑、护眼三种主题模式的动态切换。
