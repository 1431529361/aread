还没有模型提供商

添加一个 OpenAI 兼容端点（名称 + Base URL + 密钥 + 模型），即可开始 AI 问答。支持硅基流动、阿里云百炼、DeepSeek、智谱等平台。

密钥安全

  • API 密钥使用 AES-256 加密后存储在本机服务器，不会发送到任何第三方。
  • 保存密钥前会先向对应端点发起一次验证请求，确认可用后才写入。
  • 删除提供商会同时删除其密钥；删除后 AI 功能将暂停，直到重新配置。

智能索引（RAG）

为书籍建立向量索引，让 AI 在全书范围内做语义检索。未配置时自动使用 BM25 关键词检索。

自定义端点

OpenAI 兼容 Base URL，系统自动补全 /embeddings；模型须输出 1024 维向量

说明

  • 向量化用于建立书籍智能索引，提升 AI 全书检索的语义理解能力。
  • 未配置时自动降级为 BM25 关键词检索，功能不受影响。
  • 更换提供商后，建议对已索引的书籍重建索引。

重排序（Rerank）

在 BM25 与向量融合之后，对候选片段做一次精排，提升引用相关性。

未启用

OpenAI 兼容 /rerank 端点；未填 /rerank 时系统自动补全

说明

  • 重排默认关闭；启用后会增加一次模型调用与少量延迟，建议按需开启。
  • 重排失败时自动保留融合原排序，不中断检索。
